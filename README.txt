MOVIX — Site vitrine HTML/CSS/JavaScript

Démarrage : ouvrez index.html dans un navigateur.
- Les images du dossier images/ sont fournies avec le site.
- Recherche, filtres par genre, fiches, liste personnelle et page d'indisponibilité sont intégrés.
- Aucun fichier vidéo n'est hébergé et aucun téléchargement réel n'est effectué.

Personnalisation : ouvrez index.html dans un éditeur de texte. Les titres et métadonnées sont dans le tableau `movies` du script.
