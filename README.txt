MOVIX — PACK AVEC SOURCES TXT ET PAGES REDESIGNEES

PAGES UTILISABLES
- index.html : accueil, catalogue, recherche et sélection quotidienne.
- detail.html : fiche de titre avec présentation améliorée ; X-Men mène au téléchargement.
- download.html : page de téléchargement stylisée et limite locale d’un lancement par jour.
- unavailable.html : page d’indisponibilité stylisée.

COPIES TEXTE DES SOURCES
- index.txt
- detail.txt
- download.txt
- unavailable.txt
Chaque fichier .txt contient le code source de la page HTML correspondante. Pour que le site fonctionne, garde les fichiers .html.

FICHIERS A AJOUTER
- images/X-Men Cover.png : place ici ton image d’affiche sous ce nom exact.
- films/X-Men.mp4 : place ici une vidéo que tu es autorisé à partager sous ce nom exact.

INSTALLATION
1. Décompresse le pack.
2. Ajoute l’affiche dans images/ et le fichier vidéo autorisé dans films/.
3. Déploie tout le dossier sur un hébergement HTTP/HTTPS.
4. Ouvre index.html sur le site, recherche X-Men, puis ouvre sa fiche.

IMPORTANT
Le pack ne contient ni le film commercial X-Men ni son affiche. La limite d’un téléchargement par jour est enregistrée dans le navigateur ; elle n’est pas sécurisée côté serveur et peut être contournée en effaçant les données du navigateur ou en utilisant un autre appareil. Une vraie limite exige un serveur et une base de données.
